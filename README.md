# Student Performance Analyzer

## Description
A Python application that collects student information,
classifies academic performance, calculates statistics,
and generates a performance report.

## Features
- Collects information for at least five students
- Validates scores between 0 and 100
- Classifies grades using conditional statements
- Uses lists, tuples, and dictionaries
- Calculates average, highest, and lowest scores
- Counts passed and failed students
- Identifies the top student

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run the following command:

   python main.py
